# تطبيق القادسية (Flutter)

البنية (طبقات منفصلة لكل ميزة):

```
lib/
  app/            التطبيق والمسارات (go_router) وربطها بحالة الدخول
  core/           الهوية البصرية، الإعدادات، التخزين الآمن، معرف الجهاز، المكونات المشتركة
  features/
    auth/         domain (النماذج والعقود) / data (الاتصال بالسيرفر) / application (الحالة) / presentation (الشاشات)
    home/         الشاشة الرئيسية بالبطاقات الخمس
```

- الخط: Cairo (رخصة OFL، الملف في `assets/fonts/cairo/OFL.txt`).
- الشعار: `assets/brand/logo.png` هو الأصل كما هو، و`logo_trimmed.png` هو نفس الملف بعد قص الهوامش الشفافة فقط.
- عنوان السيرفر يُمرر بـ `--dart-define=API_BASE_URL=...`.

راجع `README.md` في جذر المستودع لأوامر التشغيل والاختبار.
