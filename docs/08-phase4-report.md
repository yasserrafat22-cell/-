# تقرير التطوير — السجل، الكتالوج، المواقع، المرفقات (الإصدار 0.4.0)

- الفرع: `claude/qadisiyah-analysis-planning-i2wgtx` (لا دمج في main، لا نشر إنتاج)
- التصميمات المعتمدة: `docs/phase4/proposals/` — لقطات التطبيق الحالية: `docs/phase4/full/`

## الوظائف المنفذة

| الدفعة | ما تم |
|---|---|
| 1. الخامات | شركات مصنّعة منفصلة عن الموردين؛ Grade = خامة + شركة + كود؛ بلدان صنع متعددة لكل Grade؛ بلد صنع اختياري في كل بند؛ مواصفات مفتوحة «أي شركة» للعملاء (مختلفة عن «غير محدد» وعن «الشركة غير محددة» للبيانات السابقة)؛ المندوب يضيف «بانتظار التحقق» والمدير يعتمد؛ كتالوج للإدارة (بطاقة «الإدخال السريع / إعدادات» لمن لديه صلاحية البيانات الأساسية) |
| 2. السجل | من بطاقة «البحث عن موردين أو عملاء»: عملاء/موردون/مفضلة، بحث بالاسم والهاتف (كامل أو جزء) والخامة والشركة والـ Grade وبلد الصنع، فلاتر، تمييز «مطابقة مفتوحة»، فتح الملف بالضغط، زر تعديل واضح، المفضلة، تاريخ الإنشاء وآخر تعديل، سجل مختصر للتعديلات (من/متى/ماذا) |
| 3. المواقع | مواقع متعددة (مقر، مصنع، مخزن، تحميل، تسليم) بلصق رابط Google Maps أو موقع الهاتف بإذن أو إحداثيات يدوية؛ الرابط الأصلي يُحفظ دائمًا؛ فتح/نسخ/مشاركة؛ موقع لكل طلب/توريد دون تغيير الافتراضي؛ «إرسال للسائق» عبر المشاركة اليدوية |
| 4. المرفقات | شعار، صور منتجات، TDS (PDF مرتبط بخامة وشركة وGrade محدد)، ملفات أخرى؛ عرض ومشاركة (واتساب وغيره)؛ تخزين في volume دائم مستقل؛ وصول عبر السيرفر فقط بالصلاحيات؛ داخل النسخ الاحتياطي والاستعادة |
| 5. يومي | تكرار بند سابق، اتصال بالضغط على الرقم، مشاركة بيانات التواصل |

## ترحيلات قاعدة البيانات (كلها إضافية)

1. `CatalogManufacturersOrigins`: جداول `manufacturers` و`grade_origins`، وأعمدة اختيارية للشركة/التحقق/بلد الصنع/المواصفات المفتوحة. التعديل الوحيد: استبدال فهرس عدم تكرار الـ Grade بفهرس أوسع (خامة + شركة + كود) مع `NULLS NOT DISTINCT` — معتمد بالاسم في اختبار أمان الترحيلات، ولا يحذف بيانات.
2. `RegistryFavorites`: جدول `user_favorites`.
3. `PartyLocations`: جدول `party_locations` وعمودا موقع التسليم/التحميل في الطلبات والتوريدات.
4. `Attachments`: جدول `attachments`.

## الاختبارات

| الجزء | النتيجة |
|---|---|
| السيرفر | 96 ناجح (منها: الكتالوج والمواصفات، السجل، المواقع، المرفقات، الترقية من مخطط المرحلة 3) |
| التطبيق | 128 ناجح + تحليل بلا ملاحظات |
| CI: تحديث السيرفر الحقيقي | من `ff9087b` ومن المرحلة 3: بقاء حساب admin وكلمة مروره والجلسة و`.env` والـ volume، ثم رفع ملف ← نسخة احتياطية ← فقد بيانات ← استعادة ← تطابق الملف وقاعدة البيانات |
| CI: تحديث APK | تثبيت إصدار المرحلة 3 ثم الجديد فوقه على محاكي مع بقاء البيانات |

## يحتاج تجربتك

1. اختيار الخامة وإضافة Grade جديد، واعتماده من الكتالوج.
2. لصق روابط Google Maps حقيقية من هاتفك (الروابط المختصرة تُحفظ كما هي).
3. رفع شعار وملف TDS ومشاركتهما عبر واتساب.
4. بعد التحديث: `bash backup-trial.sh` والتأكد من ظهور ملف `attachments-*.tar` بعد رفع أول ملف.
