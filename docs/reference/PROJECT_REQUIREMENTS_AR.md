# القادسية لتجارة مواد خام البلاستيك — مستند تسليم المتطلبات إلى Claude Code
تاريخ التوثيق: 2026-10-27

## الحالة والأولوية
هذا المستند يلخص اتفاقات تصميم المنتج خلال المحادثة ويرفق صورًا توضيحية. **لم يُبنَ تطبيق فعلي بعد، ولم تُنشأ قاعدة بيانات ولم تُفعّل وظائف الاتصال والاستيراد والتصدير.** الصور لتوضيح الاتجاه البصري وليست ملفات تصميم تفاعلية، وتتضمن أحيانًا بيانات تجريبية أو نصوصًا غير دقيقة. اعتمد المتطلبات المكتوبة المرجع الوظيفي عند التعارض مع صورة.

## الهوية والمنصات
- اسم النظام: القادسية لتجارة مواد خام البلاستيك.
- استخدم الشعار المرفق `gigapixel-Gemini_Generated_Image_75zf0875zf0875zf.png` والهوية البصرية الأزرق والأخضر، مع واجهات عربية RTL.
- تصميم Responsive مع **390 × 844 px** كمرجع للموبايل و**1440 × 900 px** كمرجع للّاب؛ المقاسات نماذج وليست قيودًا ثابتة.
- تخطيط اللاب أعمدة وجداول عند الحاجة؛ على الموبايل بطاقات وتبويبات وقوائم قابلة للتمرير.
- الصفحة الرئيسية: خمس وظائف (تسجيل الموردين، تسجيل العملاء، البحث الذكي، إنشاء واستخراج التقارير، الإدخال السريع وإدارة البيانات الأساسية).
- شاشة تسجيل الدخول: اسم المستخدم، كلمة المرور، زر دخول، إظهار/إخفاء كلمة المرور، ومسار آمن لاسترجاع الحساب.

## الموردون
- تسجيل سريع لا يمل المستخدم: الاسم، الهاتف، النوع/النشاط، المندوب المسؤول (يُحدد من حساب الموظف إذا مناسبًا)، والخامات المتاحة.
- استكمال الموقع لاحقًا: محافظة ومنطقة وعنوان وإحداثيات اختيارية على الخريطة.
- المورد الواحد له عدة خامات/منتجات، وكل منتج قد يحمل Grade وداتا شيت PDF/JPG/PNG خاصة به. الداتا شيت اختيارية.
- الأسعار اختيارية لكل خامة/Grade: القيمة، العملة، وحدة السعر، تاريخ العرض، الصلاحية، ملاحظات تشمل الضريبة أو النقل؛ **احتفظ بتاريخ الأسعار السابق ولا تستبدله**.
- ملف المورد: المنتجات، آخر توريد وكميته، آخر اتصال، المندوب، العنوان، سجل الأسعار، واتساب، الاتصال، زر تسجيل تواصل، تسجيل توريد.
- لا تساوِ سعرًا قديمًا بتوفر مخزون أو عرض ما زال صالحًا.

## العملاء
- تسجيل سريع: الاسم، الهاتف، نوع النشاط (مصنع/تاجر/موزع/أخرى)، المندوب المسؤول، الخامات المهتم بها. البريد والموقع والملاحظات اختيارية ويمكن استكمالها لاحقًا.
- **لا تضع حقل داتا شيت في تسجيل العميل**؛ هذه الإضافة حُذفت صراحة.
- العميل له عدة خامات مطلوبة وGrades وكميات عند توافرها، ويمكن تسجيل كمية الطلب الشهري المتوقعة اختياريا.
- ملف العميل: آخر طلب وتاريخه وكمية آخر طلب، آخر تواصل، المندوب، النشاط، المنطقة والخامات المطلوبة، زر طلب جديد وتواصل جديد.
- الاتصال: نوع التواصل اتصال/واتساب/زيارة/أخرى، نتيجة التواصل (تم/لم يرد/يحتاج متابعة/استفسار)، ملاحظات اختيارية، موعد متابعة مستقبلية.
- الطلب: تاريخ، عدة خامات مع Grade وكميات ووحدات، حالات الطلب مع التمييز بين استفسار/عرض سعر/طلب مؤكد/منفذ أو ملغي.
- آخر طلب وآخر اتصال يُستخرجان من الأحداث المسجلة، لا من خانات تكرارية يملأها المستخدم.
- تصنيفات نشط/بحاجة متابعة/متوقف مبنية على قواعد محددة قابلة للضبط لا أحكام تخمينية.

## البحث الذكي — أولوية مرتفعة
- مربع بحث موحد يقبل خامة، Grade، اسم عميل أو مورد، أو رقم هاتف.
- اقتراحات فورية أثناء الكتابة؛ البحث الجزئي وتصحيح الأخطاء البسيطة وتطبيع صور الحروف العربية والتعرف على المرادفات/الاختصارات الإنجليزية مثل PP/PVC/HDPE.
- عند البحث عن خامة، يظهر العملاء المهتمون أو المشترون على جانب والموردون المطابقون على الجانب الآخر في اللاب؛ بالموبايل تبويبات العملاء والموردين.
- النتائج قابلة للنقر لفتح تفاصيل الطرف وتاريخ التعاملات؛ لكل نتيجة اتصال وواتساب ضمن حدود صلاحيات المستخدم.
- عند اختيار عميل تظهر الخامات والاستفسارات والطلبات والموردون المطابقون؛ عند اختيار مورد تظهر خاماته والعملاء الذين اشتروا أو استفسروا عن نفس المادة.
- طابق على مستوى Grade والمواصفات والوحدة، لا اسم المادة فقط؛ ميّز «مطابقة بيانات مسجلة» من «مطابقة محتملة تحتاج تأكيد»، ولا توحِ بتوفر حقيقي دون تحقق.
- فلاتر: نوع كيان، المحافظة، المندوب، الخامة، Grade، حالة العميل أو المورد، آخر تعامل، استفسر دون شراء.
- سجل فرصة بيع تربط عميلا وموردا وخامة وكمية وحالة ومندوب مسؤول. قارن الموردين بأسعار موحّدة العملة والوحدة وعرض تاريخ السعر.
- تنبيهات داخل النظام عند ظهور تطابق جديد أو موعد متابعة أو سعر يحتاج تحديثًا، مع تجنب الإزعاج.

## التقارير داخل التطبيق
- شاشة نظرة عامة ثم مركز التقارير ثم تفاصيل التقرير، مع فلاتر وحالات وإحصائيات، وتقسيم لاب/موبايل مناسب.
- تقارير العملاء: كل العملاء، حسب النشاط والمنطقة والمندوب والخامة، تأخر الشراء، العملاء النشطون، أهم العملاء بالكميات، طلبات واستفسارات، متابعات اليوم، فرص مفتوحة، تكرار الشراء، مقارنة الفترات.
- تقارير الموردين: كل الموردين، المواد والـ Grade، آخر توريد، آخر أسعار وتواريخها وتاريخ الأسعار، الموردون المتوقفون، المتابعات، المندوب، الداتا شيت الناقصة، المقارنة بين موردين، صلاحية الأسعار.
- التقرير الشامل: أسماء العملاء والموردين، خامات وGrades، طلبات وكميات، حالات، مؤشرات، فرص مطابقة، التنبيهات، وعند وجود بيانات معاملات مكتملة يمكن إظهار المبيعات والأرباح مع فصل «المتوقع» عن «الفعلي».
- مؤشرات الجودة: السجلات ناقصة الهاتف أو المندوب أو Grade أو الملف الفني، الأسعار القديمة وغيرها. لا تعرض نسبًا غير صحيحة أو مجاميع لا تطابق تفاصيلها.
- أسماء الأشخاص/الشركات والأرقام والكميات والنسب المرسومة في الصور كلها **بيانات افتراضية**.

## الطباعة وPDF
- التقرير على الشاشة تفاعلي؛ **القالب الرسمي بحجم ورق A4 يظهر فقط عند أمر معاينة/طباعة أو تصدير PDF** ولا يُعرض كواجهة تشغيل عادية.
- في التصدير PDF والطباعة، تكرار عناوين الجداول وترقيم الصفحات واستمرار الصفوف عبر أكثر من A4 مع قراءة سليمة للعربية وRTL.
- رقم هاتف العميل/المورد يظهر بوضوح؛ في ملف PDF الرقمي يمكن جعل الرقم رابط `tel:+20...` أو حسب الدولة/الصيغة، وتظهر أيقونة واتساب عند وجود رقم مُسجل. على الورق يظهر الرقم مطبوعًا فقط. وظائف الروابط تعتمد على عارض PDF والجهاز.
- التصدير Excel بيانات منظمة قابلة للفرز والتحليل، وليس صورة من PDF.
- يمكن جعل QR للتقرير الإلكتروني بعد وجود عنوان حقيقي مؤمّن؛ لا تصنع رابطًا وهميًا.

## الإدخال السريع والإعدادات
- أيقونة خامسة في الصفحة الرئيسية بعنوان «الإدخال السريع» أو «الإدخال السريع والإعدادات».
- منها: استيراد Excel، تسجيل خامة وGrade جديدين، إدارة المندوبين، إنشاء وحدات وأوزان جديدة مع معاملات تحويل صحيحة، إضافة أنواع نشاط ومناطق وحالات متابعة وقوائم أساسية بدون تعديل الكود.
- الاستيراد ليس حفظا أعمى: قراءة وتعيين الأعمدة، معاينة الصفوف، التحقق من الحقول، كشف التكرار وتعارض الهويات، إظهار أخطاء قبل الموافقة، ثم استيراد مضبوط مع تقرير سجلات مضافة ومحدّثة ومرفوضة.
- الوحدات والأوزان لا تدخل بعلاقات تحويل غامضة: اعتمد وحدة قياسية ومضاعفات واضحة. التغييرات الأساسية بصلاحية المدير.

## الأمان والحوكمة
- دخول محمي وجلسات وصلاحيات منفصلة (مدير/مندوب/إدارة) مع حماية أسعار الشراء والأرباح والتقارير الحساسة؛ تحكم بالصلاحية على الخادم/API وليس إخفاء واجهة فقط.
- احفظ أرقام الهاتف بصيغة قابلة للتوحيد، اسم بديل واتساب عند اختلافه، وامنع التكرار المنطقي دون دمج تلقائي خطر.
- لا تعدّ الضغط على الاتصال تواصلا ناجحا دون تسجيل النتيجة.
- سجل تغييرات الأسعار والبيانات الأساسية وتعديلات الاستيراد لتعقب من فعل ماذا ومتى.

## تعليمات لClaude Code
1. راجع الصور ومستند المتطلبات قبل اقتراح التقنية أو الهيكل.
2. أنشئ تصميم UI قابل للتنفيذ للاب والموبايل، مع مكونات موحدة، ولا تفترض أنّ رسوم الصور دقيقة لغويًا أو حسابيًا.
3. قبل بناء التطبيق، قدم مخطط قاعدة بيانات وعلاقات العملاء/الموردين/الخامات/Grades/الطلبات/التوريدات/التواصل/الأسعار/الفرص/الاستيراد/الأدوار، وحالات الاستخدام والاختبارات.
4. لا تنفذ نشرًا أو تغييرات دائمة أو استيراد بيانات حقيقية دون موافقة صريحة.
